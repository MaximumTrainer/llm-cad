Features

Everything an LLM needs to go from text to print-ready 3D model.

🔒

Sandboxed Execution

Model code runs in a subprocess with a 30-second wall-clock timeout, a memory cap, no network, and writes confined to the session directory. A barrier against accidents and casual misuse — not a jail for deliberately hostile code, so put OS-level isolation around it before exposing it to untrusted prompts.

📸

Multi-Angle Rendering

Four-view grid (front, right, top, isometric) with axis triad and mm scale ticks. Renders return as inline images the LLM can see and critique.

✅

Print Validation

Checks watertightness, manifold status, wall thickness, overhang angles, and estimates PLA mass. Catch issues before printing.

📦

Multi-Format Export

Export to STL, STEP, 3MF, and GLB. STEP preserves exact B-rep geometry. Assembly export writes named shapes via XCAF.

🧩

Multi-Part Assembly

Design assemblies with up to 16 named parts. Position, color, interference detection, and clearance measurement between parts.

🤖

AI Mesh Generation

Generate organic shapes (figurines, terrain) via the Meshy API, then combine with parametric CadQuery parts.

🌐

Dual Transport

Stdio for local hosts (Claude Code, Claude Desktop) and streamable HTTP for remote clients with bearer token auth and CORS.

📖

Built-in Teaching

Ships MCP prompts that teach the LLM how to use CadQuery, follow the design workflow, and check printability. No prior knowledge needed.

📐

Precision Measurements

Bounding box, volume, face count, face-to-face distance, and inter-part clearance. The LLM verifies its own dimensions.

Tools

14 MCP tools the LLM calls to design, validate, and export models.

Tool Description Category
execute_cad Run CadQuery Python code in a sandbox. Assign result to result. Core
render_views Render multi-angle PNG preview (front, right, top, isometric). Core
validate_mesh Check watertight, manifold, wall thickness, overhangs, PLA mass estimate. Core
measure Numeric measurements: bounding box, volume, face count, distance, clearance. Core
export_model Export to STL, STEP, 3MF, or GLB. Per-part and assembly modes. Core
gen_ai_mesh Generate organic 3D mesh via Meshy API (requires MESHY_API_KEY). AI
create_part Add a named part to the assembly. Assembly
set_active_part Switch which part execute_cad targets. Assembly
position_part Set translation (mm) and rotation (degrees) for a part. Assembly
list_parts Overview of all parts: name, color, position, bounding box. Assembly
delete_part Remove a part from the assembly. Assembly
list_session Show parts, code history, and exports for the current session. Session
reset_session Clear all state and start fresh. Session
ping Liveness check. Answers from the server process, so it confirms the server survived a kernel fault. Session

Quick Start

Up and running in under 5 minutes.

1. Install

git clone https://github.com/MaximumTrainer/llm-cad.git && cd llm-cad
uv sync

2. Connect to Claude Code

claude mcp add cad-mcp -- uv run cad-mcp

3. Connect to Claude Desktop

Add to your claude_desktop_config.json:

{
  "mcpServers": {
    "cad-mcp": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/llm-cad", "cad-mcp"]
    }
  }
}

4. Run the smoke test

uv run python scripts/smoke.py
